# 🐍 100 Days of Python

Welcome to my **100 Days of Python** journey! 🚀

This repository contains the projects, exercises, and practice work I complete while following **100 Days of Code: The Complete Python Pro Bootcamp** by **Dr. Angela Yu**.

The goal of this challenge is to build a strong foundation in Python through consistent practice and hands-on projects.

---

## 📚 About the Course

**100 Days of Code: The Complete Python Pro Bootcamp** is a project-based Python course covering everything from the fundamentals to more advanced programming concepts.

Throughout the course, I will be working on different projects while learning topics such as:

- Python fundamentals
- Data types and variables
- Control flow
- Functions
- Lists, dictionaries, and other data structures
- Object-Oriented Programming
- File handling
- APIs
- Web development
- Automation
- Data analysis
- And more
