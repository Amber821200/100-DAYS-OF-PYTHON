# 🎸 Band Name Generator

My first Python project from **Day 1** of **100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📖 About the Project

The Band Name Generator is a small Python program that creates a possible band name from two pieces of information entered by the user.

The user is asked for:
- Their hometown or the city they grew up in
- Their pet's name

The program then joins both inputs together and displays the generated band name.

---

## 🛠️ Python Concepts Used

- `print()` for displaying messages
- `input()` for collecting user responses
- Variables
- String manipulation and concatenation
- Basic Python program structure

---

## 💻 Built With

**Python 3**

## 🎯 Takeaways

This project was my first hands-on exercise with Python. It helped me get comfortable with taking input from the user and using that data within a program.

I also got some initial practice with variables and working with strings to create dynamic output.

Although it's a simple project, it introduced me to the basic building blocks I'll be using throughout the rest of the 100 Days of Python challenge.
